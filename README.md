# 💰 Expense Tracker

A web application for tracking personal expenses. Users can add, view, edit and delete expenses, grouped by month, with a total spending overview.

## ✨ Features

- Add an expense (name, amount, category, date)
- View all expenses grouped by month
- Total amount per month and overall
- Edit and delete expenses
- Expense categories (food, transport, entertainment...)
- Modern, responsive design

## 🛠️ Tech Stack

- **Angular 20** (standalone components)
- **TypeScript**
- **HTML & CSS** (glassmorphism design, animations)
- **localStorage** for data persistence

## 🚀 Getting Started

You need Node.js and Angular CLI installed.

```bash
# go into the frontend folder
cd frontend

# install dependencies
npm install

# run the app
ng serve
```

The app runs on `http://localhost:4200`
